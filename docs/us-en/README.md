## Three steps to integrate

1. **Configure**: get an API key and target URL; V2/V2s also require a stable proxy.
2. **Send**: replace the host, preserve the path and body, and add the required headers.
3. **Verify**: check `x-cb-status`, then the target HTTP status and business content.
