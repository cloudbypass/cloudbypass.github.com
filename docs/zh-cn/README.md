## 接入只需三步

1. **准备配置**：获取 API Key，确认目标 URL；V2/V2s 还需稳定代理。
2. **发送请求**：替换主机，保留路径和请求体，带上必要请求头。
3. **验证结果**：检查 `x-cb-status`，再检查目标 HTTP 状态及业务内容。
